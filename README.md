# 🧴 ProBeauty App

ProBeauty App is a Flutter-based mobile application designed to help users browse, book, and manage beauty and salon appointments with ease.  
It provides a smooth and modern interface for both customers and service providers.

---

## 🚀 Installation & Setup

Follow these steps to get started with the project on your local machine:

### 1️⃣ Clone the repository
```
git clone https://github.com/LegitFR/ProBeauty-App.git
cd ProBeauty-App
```
2️⃣ Install dependencies
Make sure you have Flutter SDK installed and properly configured.
Then, fetch all the required packages:

flutter pub get
```
3️⃣ (Optional) Clean the build cache
If you face any issues with dependencies or builds:

flutter clean
flutter pub get
```
▶️ Running the App
Once dependencies are installed, you can run the app on your preferred device or emulator.

Run on a connected device or emulator
flutter run
```
Run on a specific platform
Android:
flutter run -d android
```
iOS (Mac only):
flutter run -d ios
```
Web:
flutter run -d chrome
```
Build for release
To create a release build (APK):
```
flutter build apk --release
```
